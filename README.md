# Hacker Terminal Quest

> A browser mini-game that teaches real SSH and PowerShell commands through a "hacker terminal" story mode.

You play ShadowByte, a new recruit of the Neon Collective, typing real SSH and PowerShell commands into a glowing green terminal to complete missions, breach systems, and level up. It's a single self-contained HTML page — no server, no build step, no backend.

## Features
- Story-driven mission structure ("NEON COLLECTIVE RECRUITMENT PROTOCOL") with a built-in tutorial screen.
- A styled, animated terminal UI (matrix-style background, glow effects, glitch animation) built with Tailwind.
- Real command input that's checked against expected SSH/PowerShell syntax, with success/fail feedback states.
- Score ("HACK POINTS") and level tracking as you progress through missions.
- Runs entirely client-side — open the HTML file and play, nothing to install.

## Stack
Plain HTML/CSS/JS, Tailwind CSS (via CDN), Font Awesome icons, Google Fonts (VT323 monospace).

## Getting started
**Requirements** — any modern browser. No install, no server.

**Run**
```bash
# just open the file
index.html
```
